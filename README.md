# WAHID FX — یوزربات تلگرام (منشی شخصی)

این یه بات نیست که جدا باهاش چت کنی — روی **خود اکانت تلگرام خودت** اجرا میشه و فقط به دستورات **خودت** (پیام‌هایی که خودت می‌فرستی) واکنش نشون میده.

## قابلیت‌ها

- **پیام‌های حذف‌شده** — هر پیامی تو چت‌هات حذف بشه، متنش رو تو "Saved Messages" (پیام‌های ذخیره‌شده) خودت لاگ می‌کنه.
- **آنتی‌لاگین** — به محض اینکه پیام رسمی تلگرام با کد ورود (Login code) بیاد، خودکار همه سشن‌های دیگه رو قطع می‌کنه (به‌جز همین کانکشن بات) و بهت تو Saved Messages خبر میده.
- **پاسخ خودکار آفلاین (Away)** — با `.away پیامت` روشنش کن، با `.back` خاموشش کن.
- **یادآوری/تسک** — با `.remind 25m زنگ بزن به فلانی` یه یادآوری تنظیم می‌کنه.
- **پاسخ به کلمات کلیدی** — با `.addkeyword سلام | چطوری؟` یه پاسخ خودکار برای اون کلمه تنظیم می‌کنه.

لیست کامل دستورات تو فایل `bot.py` بالای فایل نوشته شده (`.help` هم تو تلگرام همون رو نشونت میده).

⚠️ **مهم:** این روی اکانت شخصی خودت اجرا میشه، نه یه بات جدا. فقط برای کارهای شخصی استفادش کن (نه اسپم/پیام انبوه)، چون تلگرام به رفتار غیرعادی حساسه و ممکنه اکانت محدود بشه.

---

## مرحله ۱ — گرفتن API_ID و API_HASH

1. برو به [my.telegram.org](https://my.telegram.org) و با شماره تلگرامت لاگین کن.
2. برو تو بخش **API development tools**.
3. یه اپ جدید بساز (اسم دلخواه، مثلاً "WAHID FX Bot") — بعدش یه `api_id` و `api_hash` بهت میده. اینا رو یه‌جا کپی کن، بعداً لازمشون داری.

## مرحله ۲ — ساخت SESSION_STRING (روی کامپیوتر خودت)

این یه‌بار باید روی کامپیوتر خودت (نه روی Render) اجرا بشه، چون باید کد ورود رو دستی وارد کنی:

```bash
pip install telethon
python generate_session.py
```

ازت `API_ID` و `API_HASH` رو می‌پرسه (همونایی که مرحله ۱ گرفتی)، بعد شماره تلفن، بعد کد ورودی که تلگرام برات می‌فرسته (و اگه رمز دو مرحله‌ای داری، اونم). در آخر یه رشته طولانی چاپ می‌کنه — این **SESSION_STRING** توئه. کاملاً مثل رمز عبورت مراقبش باش، هیچ‌جا شیر نکن.

## مرحله ۳ — دیپلوی روی Render (رایگان)

⚠️ **آپدیت مهم:** الان دیگه Render برای "Background Worker" هیچ پلن رایگانی نداره — فقط **Web Service** پلن رایگان داره. برای همین بات رو یه‌کم عوض کردم تا به‌عنوان Web Service قابل اجرا باشه (یه سرور کوچیک وب داخلش اضافه شده که فقط جواب "OK" میده، همین کافیه تا Render قبولش کنه).

1. یه اکانت تو [render.com](https://render.com) بساز (میتونی با گیت‌هاب واردش بشی).
2. این پوشه (`wahid-userbot`) رو تو یه ریپازیتوری گیت‌هاب آپلود کن.
3. تو داشبورد Render، رو **New +** بزن و این‌بار **Web Service** رو انتخاب کن.
4. ریپازیتوری گیت‌هابت رو وصل کن.
5. تو تنظیمات سرویس:
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
   - **Instance Type:** Free
6. برو تو بخش **Environment** و این سه‌تا متغیر رو اضافه کن:
   - `API_ID` = همون عددی که از my.telegram.org گرفتی
   - `API_HASH` = همون رشته‌ای که گرفتی
   - `SESSION_STRING` = همون رشته‌ای که مرحله ۲ ساختی
7. **Deploy** بزن.

بعد از چند دقیقه، تو Saved Messages خودت باید پیام `✅ WAHID FX userbot is online.` رو ببینی — یعنی بات روشنه. آدرس سرویس (چیزی شبیه `https://wahid-fx-userbot.onrender.com`) رو هم یه‌جا کپی کن، تو مرحله بعد لازمش داری.

## مرحله ۴ — بیدار نگه‌داشتنش (خیلی مهم، رایگان)

پلن رایگان Web Service در Render بعد از ۱۵ دقیقه بی‌کاری (هیچ درخواستی نیومده باشه) خودش رو **می‌خوابونه**. برای اینکه بات واقعاً ۲۴/۷ بمونه، باید یه سرویس رایگان دیگه هر چند دقیقه یه‌بار به آدرس بات سر بزنه تا بیدار بمونه:

1. برو [uptimerobot.com](https://uptimerobot.com) و یه اکانت رایگان بساز.
2. دکمه **"+ Add New Monitor"** رو بزن.
3. Monitor Type رو بذار **HTTP(s)**.
4. تو URL همون آدرس Render رو بچسبون (مثل `https://wahid-fx-userbot.onrender.com`).
5. Monitoring Interval رو بذار **5 minutes**.
6. Save کن.

از این به بعد UptimeRobot هر ۵ دقیقه یه‌بار به بات سر می‌زنه و نمی‌ذاره بخوابه — یعنی واقعاً ۲۴/۷ آنلاین می‌مونه، همه‌ش رایگان.

## اگه خواستی چیزی اضافه/عوض کنی

کد تو `bot.py` واضح و کامنت‌گذاری‌شده‌ست — هر بخش (away، reminder، deleted-log، anti-login) جدا از هم نوشته شده. اگه خواستی قابلیت جدیدی اضافه کنم (مثلاً وصل کردنش به همون سیستم POS یا ژورنال معاملاتیت)، بگو تا اضافه کنم.
